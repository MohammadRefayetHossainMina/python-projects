Blackjack

A recruiter-ready table you can play in the browser. Same game I first wrote as a Python command-line project, rebuilt here with HTML, CSS, and JavaScript so you do not need to install anything.

  • HTML5
  • CSS3
  • JavaScript
  • GitHub Pages

What this shows

  • Fisher–Yates shuffled six-deck shoe (not random cards with replacement)
  • Ace scoring as 1 or 11, natural blackjack, and dealer stand on 17
  • Game state: betting, player turn, dealer draw, and payout
  • Hit, stand, and double down, with 3:2 blackjack payout

Demo only — no real money. Press H, S, or D during your turn, or Enter to deal.
